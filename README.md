# 수학 왕국: 사라진 9개의 열쇠

FINAL V13 RPG 전투 버전입니다. 설치 없이 브라우저에서 실행되며, GitHub Pages에서 사용할 수 있습니다.

## 구현 내용

- 룬 기사·아르카나 마법사·그림자 궁수 중 직업 선택
- 마을과 길드·훈련장·여관·던전·도서관·왕성 이동
- 수학 문제 9개와 직업별 임무·전용 힌트
- 원형 아날로그 조이스틱을 이용한 대각선 이동과 속도 조절
- 체력 3칸, 경험치, 레벨 1~4, 장비 9종
- 3·6·9번 문제의 보스전과 직업별 공격 효과
- 왕립 안내인 루미의 진행 안내
- 오프닝 및 직업별 엔딩 영상, 최종 모험 결과표
- 게임 배경음악 재생·음소거
- 브라우저 진행 저장 없음: 새로고침하면 처음부터 시작

## 실행 방법

1. `index.html`과 `assets` 폴더를 같은 위치에 둡니다.
2. `index.html`을 브라우저에서 열거나 GitHub Pages 주소에 접속합니다.
3. 오프닝 이후 직업을 선택하고 모험을 시작합니다.
4. PC는 방향키/WASD, 태블릿과 휴대폰은 왼쪽 아래 원형 조이스틱으로 이동합니다.
5. 빛나는 `❗` 근처에서 오른쪽 아래 `조사` 버튼을 누릅니다.

## RPG 규칙

- 문제를 틀리면 체력이 한 칸 줄어듭니다.
- 체력을 모두 잃으면 해당 문제의 힌트가 자동으로 열리고 체력이 회복됩니다.
- 문제를 해결하면 경험치와 장비를 얻습니다.
- 힌트와 직업 기술을 사용하지 않으면 추가 경험치를 얻습니다.
- 열쇠 3·6·9개를 모을 때 레벨이 오릅니다.
- 3·6·9번 문제는 정답을 맞힌 뒤 보스 공격 연출이 재생됩니다.
- 상단의 `💬` 버튼은 진행 안내, `🎒` 버튼은 획득 장비를 보여줍니다.

## GitHub Pages 업데이트

1. 저장소 최상위의 기존 `index.html`을 새 파일로 교체합니다.
2. `assets` 폴더 안에 새 보스·공격 이미지 6개를 업로드합니다.
3. 변경 사항을 Commit합니다.
4. 1~3분 뒤 Pages 주소를 새로고침합니다.
5. 이전 화면이 보이면 주소 끝에 `?v=13`을 붙이거나 브라우저의 시크릿 창에서 확인합니다.

GitHub Pages 설정은 `Settings → Pages → Deploy from a branch → main / (root)`를 사용합니다.
